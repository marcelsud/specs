# Specs

Versioned specifications for repeatable engineering and review decisions.

## Specifications

- [Grading Methodology](./grading-methodology.md) — Evidence-backed issue,
  pull request, project, and release grading.
- [Multi-Agent Review Agreement](./multi-agent-review-agreement.md) — A
  bounded protocol for converging multi-agent reviews without cosmetic churn.
- [Continuous Audit](./continuous-audit.md) — A one-topic-per-run audit loop
  that supplies eligible, reproduced issues without rediscovery or fabrication.

Each specification declares its version at the top of the document. Changes
that alter normative behavior should update that version.
